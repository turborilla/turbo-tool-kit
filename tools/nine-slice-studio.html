Help / shortcuts

Edit only in the nine-slice view. All repeated copies share the same source pixels. The source view is read-only and updates as you work. The opened file is never overwritten.

Brush: B. Clone: C, then Alt-click a source point in the nine-slice view. E toggles erasing. Alt-click with the brush to pick a colour. [ and ] change brush size.

Pointer tile only (T): clips each brush, clone or eraser dab to the tile under its centre, even when the brush is larger than that tile. The active tile is outlined; it follows the pointer across seams. No paint wraps around the tile edge. This temporarily overrides Wrap in slice. Repeated copies of the same source slice still update together. Selections and pastes are unaffected.

Select: M, then drag a rectangle in the nine-slice view. Ctrl/Cmd+C copies, X cuts, V pastes. The app has a local image clipboard, so no clipboard permissions are required.

Paste: drag the outlined patch, or use arrow keys (Shift for 10 pixels). Lower paste hardness softens its edges; 100% keeps hard edges. Opacity adjusts the whole patch. Enter or Apply commits; Escape or Cancel discards it. Both views show the actual mapped result before you apply.

Linked pixels: a paste spanning repeated tiles can reach the same source pixel more than once. The strongest alpha is used once (later pixels win equal-alpha ties), so aliases do not multiply opacity.

Navigation: wheel to zoom, Space+drag or middle drag to pan. Drag anywhere in the source view to pan. 1 fits the editor; 2 fits the source. Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z redoes. Escape clears a selection.
